## Workflow

It is possible that you pick the task from any of this points. read MEMORY.md to see where the task is and what you should do.

1. Read MEMORY.md to pick up the task where the last agent left it
2. Read NOTES.md to check if there is something important another agent has written
3. Explore the repository to find the relevant files for the task. Document you findings on MEMORY.md
4. Plan the needed changes to fullfil the task and propose it to the user. 
5. Consider any feedback provided by the user on the planing. Document The final plan on MEMORY.md
6. Implement the changes and document it on MEMORY.md. The user will test them, consider any feedback provided by the user
7. Write a report to summarize all the work done
